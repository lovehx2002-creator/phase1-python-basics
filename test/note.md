# 学习日志

## 1 io 讲东西写入文件

- 使用 with open （）as file
    这个里面要使用 文件名（位置一般在默认路径下面）， 模式 ， 编码形式。
- 常用模式有三种
    1.“w” 写入模式，往文件里写东西， 一般用到 write（）方法，多次运行写入模式没有用，因为运行一次，文件里的内容会被覆盖一次
    2.“r” 读模式，讲文件夹里的东西读出来。用到 read（）方法，但是读了并不能直接输出，需要有一个东西来接收，然后在打印出来。
    3.“a” 添加模式，文件里的东西不会被覆盖，用到 write（）方法
